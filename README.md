# My Playful Recipe Book 🥞

 It’s a digital kitchen scrapbook that holds some of my favorite simple recipes. 

I wanted to make something that had little reminders of recipes which are easy and delicious.

## 🚀 What I Built

* **Floating Ingredient Background:** I wrote a JavaScript grid script that spaces out cooking emojis (like 🍕, 🍓, 🥑) so they wander around the landing page without clumping up or blocking the text.
* **Sticker Quotes:** The chef quotes on the home screen have solid borders, white backgrounds, and slight shadow offsets to look like physical scrapbook stickers pinned to a wall.
* **Dual-Screen Layout:** Instead of jamming everything onto one screen, clicking "Let's Get Cooking!" moves you to a dedicated recipe panel inspired by real-world menu cards.
* **Two-Column Panel:** The recipes page splits smoothly—ingredients stay in a tinted box on the left, and step-by-step directions sit nicely on the right.
